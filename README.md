# eot-pacientes

Sitio de información para pacientes del Grupo Colombiano de Enfermedad Ocular Tiroidea (GCEOT).

- Independiente del sitio de profesionales: sin enlaces cruzados.
- No nombra medicamentos ni fabricantes, y no guarda ni envía datos. Las pruebas (`npm test`) lo comprueban en cada publicación.
- Contenido en borrador hasta la revisión clínica del grupo.
